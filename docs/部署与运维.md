# Agent 部署与运维

## 安装

1. 将发布包解压到专用目录。
2. 从 `conf/agent.env.example` 创建 `conf/agent.env`。
3. 设置配置文件权限为 `0600`。
4. 执行 `./control.sh preflight`，并复核每个检查项。
5. 执行 `./control.sh start`，再查看状态和日志。

## 命令

- `./control.sh preflight`：输出 JSON 格式的宿主机预检结果。
- `./control.sh start`：后台启动 Agent。
- `./control.sh status`：核对 PID 和真实可执行文件。
- `./control.sh logs 200`：跟踪最近 200 行日志。
- `./control.sh restart`：优雅停止后重启。
- `./control.sh stop`：发送 `SIGTERM`，超时时拒绝强制结束。

## 故障处理

预检为 `DEGRADED` 时不得开启写模式。优先检查工具路径、libvirt 权限、网桥、受控存储目录和基础镜像目录。遇到异常只允许停止 Agent 或恢复配置，不得直接操作存量虚拟机。

## 写模式验收条件

1. 仅在无存量业务虚机的隔离 KVM 宿主机上验证。
2. 基础镜像只读，受控存储目录与其他虚机目录完全分离。
3. 使用专用网桥和测试 IP，确认无地址冲突。
4. 分别演练创建成功、启动失败回滚、幂等重试和删除。
5. 尝试删除外部域，必须被 Agent 拒绝。
6. 验收完成后先切回 `kvm-readonly`，再进行生产启用评审。
