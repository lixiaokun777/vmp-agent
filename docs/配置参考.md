# Agent 配置参考

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `AGENT_MODE` | 是 | 支持 `mock`、`kvm-readonly`和 `kvm`；新宿主机必须先使用只读模式 |
| `KVM_WRITE_ENABLED` | 是 | 写操作总开关，默认必须为 `false` |
| `KVM_WRITE_CONFIRMATION` | 是 | 写模式二次确认，启用时必须为 `enable-kvm-write` |
| `AGENT_NAME` | 是 | 平台内唯一的宿主机名称 |
| `AGENT_MANAGEMENT_IP` | 否 | 控制面可达的宿主 IPv4/IPv6 地址，用于控制台代理拨号；留空不发送此字段，由后端保留已有地址 |
| `CONTROL_PLANE_URL` | 是 | 控制面根地址 |
| `AGENT_BOOTSTRAP_TOKEN` | 首次纳管 | 首次注册令牌，不能覆盖已有同名宿主；注册完成后可清空 |
| `AGENT_HOST_ID` | 迁移/轮换时 | 导入专属运行凭据对应的宿主 UUID，首次新建留空 |
| `AGENT_RUNTIME_TOKEN` | 迁移/轮换时 | 宿主专属运行令牌，首次注册由后端生成并自动保存 |
| `AGENT_STATE_DIR` | 否 | 私有凭据与任务日志目录；直接运行默认 `/var/lib/vmlease-agent`，`control.sh` 默认发布目录 `run/state` |
| `KVM_LIBVIRT_URI` | 是 | libvirt 连接地址 |
| `KVM_VIRSH_PATH` | 是 | `virsh` 绝对路径 |
| `KVM_QEMU_IMG_PATH` | 是 | `qemu-img` 绝对路径 |
| `KVM_SEED_TOOL_PATH` | 是 | cloud-init seed 工具绝对路径；示例为 `genisoimage`，未设置时二进制默认 `cloud-localds`，无自动回退 |
| `KVM_PING_PATH` | 是 | 创建前进行 IP 占用探测的 `ping` 路径 |
| `KVM_ARPING_PATH` | 是 | iputils `arping` 路径，DAD 探测需 CAP_NET_RAW |
| `KVM_STORAGE_ROOT` | 是 | 平台专用虚机数据目录 |
| `KVM_IMAGE_ROOT` | 是 | 只读基础镜像目录 |
| `KVM_CACHE_ROOT` | 否 | 默认 `KVM_IMAGE_ROOT/.vmp-cache`；父目录不能允许其他用户/组写入 |
| `KVM_IMAGE_ALLOWED_HOSTS` | 远程下载时 | HTTPS 精确主机白名单，逗号分隔；默认空拒新下载 |
| `KVM_IMAGE_PRIVATE_HOSTS` | 私有 OSS 时 | 显式私网主机白名单，必须是 HTTPS 白名单子集 |
| `KVM_IMAGE_MAX_GB` | 否 | 单镜像上限 GiB，默认 10 |
| `KVM_IMAGE_CACHE_MAX_GB` | 否 | 总缓存上限 GiB，默认 40，不得小于单镜像上限 |
| `KVM_ALLOWED_BRIDGES` | 是 | 网桥白名单，英文逗号分隔 |
| `KVM_RUNTIME_GROUP` | 是 | libvirt QEMU 进程运行组，Ubuntu 通常为 `kvm` |
| `ALLOCATABLE_CPU` | 否 | 固定 CPU 总预算，默认 0 按逻辑 CPU 总数计算，不代表空闲 CPU |
| `ALLOCATABLE_MEMORY_MB` | 否 | 固定内存总预算 MiB，默认 40960；0 时为物理总内存减安全保留量 |
| `ALLOCATABLE_DISK_GB` | 否 | 固定磁盘总预算 GiB，默认 0 为专用目录所在文件系统总容量减安全保留量 |
| `KVM_SAFETY_MEMORY_MB` | 否 | 宿主机安全保留内存 MiB，默认 10240 |
| `KVM_SAFETY_DISK_GB` | 否 | 实例/镜像下载均保护的磁盘安全余量 GiB，默认 10 |
| `CONSOLE_LISTEN_ADDR` | 否 | 控制台代理监听地址，留空时整个功能禁用 |
| `CONSOLE_PUBLIC_URL` | 否 | 仅控制节点可达的内部 `ws://`/`wss://` 地址，浏览器走平台同源代理 |
| `CONSOLE_SIGNING_KEY` | 否 | 至少 32 个字符，必须与控制面一致 |
| `CONSOLE_ALLOWED_ORIGINS` | 否 | 允许的平台 Origin，多值用英文逗号分隔 |

可直接复制 `deployments/vmlease-agent.env.example`。示例文件的每个参数都带有中文注释。

## 配置读取与命令边界

`control.sh` 默认读取发布目录下的 `conf/agent.env`，不是当前工作目录的 `.env`。自定义位置用 `VMLEASE_AGENT_CONFIG=/绝对路径/agent.env ./control.sh preflight`，`start` 同样支持该变量；以专用账号运行时，用 `sudo -u vmlease-agent env VMLEASE_AGENT_CONFIG=/绝对路径/agent.env /opt/vmlease/vmlease-agent/control.sh start`。该文件由 shell 直接加载，只能由受信任管理员维护，含空格或 shell 特殊字符的值要正确加引号，不能把用户上传的配置直接执行。

直接执行二进制只读取环境变量，不会自动读取 `conf/agent.env`；当前仅有特殊子命令 `preflight`，没有 `--config` 或 `--version`。其他参数不能当作只读的版本检查，可能进入常规 Agent 启动流程。用发布标签、校验清单和二进制 SHA-256 确认版本。

`preflight` 不注册、写凭据或领取任务；它不校验控制面可达性/令牌、状态目录锁、控制台签名密钥或 Origin，也不完整验证工具可执行、libvirt 写权限和 ARP 能力。`status` 仅验证 PID 对应进程；注册成功、心跳及镜像/网络就绪必须在平台另行核验。

## 关键约束

- `CONTROL_PLANE_URL` 不要以 `/` 结尾，Agent 会自动追加 `/api/v1` 路径。
- `AGENT_NAME` 在整个平台内必须唯一，建议使用稳定的宿主机名，不要使用会变化的 IP。
- `AGENT_MANAGEMENT_IP` 只接受 IP 字面量，不能包含 URL、端口、CIDR、域名或 IPv6 zone，也不能使用未指定/组播地址；非法非空配置会在启动时以中文报错退出。若启用控制台而平台尚无宿主管理地址，须显式填写控制节点实际可达的 IP；Agent 不从注册连接来源或 `CONSOLE_PUBLIC_URL` 猜测地址。
- `KVM_STORAGE_ROOT` 和 `KVM_IMAGE_ROOT` 必须是不同的绝对路径，且都不能是根目录。
- `KVM_ALLOWED_BRIDGES` 只允许填写 `/sys/class/net/<名称>/bridge` 确实存在的 Linux bridge。
- `KVM_SEED_TOOL_PATH` 支持 `cloud-localds`、`genisoimage` 或 `mkisofs`，按配置路径执行，不会自动尝试其他工具；`cloud-localds` 来自 `cloud-image-utils`，`genisoimage` 来自同名软件包。
- `ALLOCATABLE_*` 是固定总预算。CPU 的 0 值取逻辑 CPU 总数；内存/磁盘的 0 值取物理总内存/文件系统总容量减对应安全保留量；非零值的实际预算取配置值与上述上限的较小值（CPU 上限为逻辑 CPU 总数），不是填大值就能突破。已有业务宿主应显式设置保守 CPU/内存/磁盘预算，不把自动值理解成当前空闲量。
- 实际安全余量另行计算为 `MemAvailable - KVM_SAFETY_MEMORY_MB` 和目录所在文件系统可用空间减 `KVM_SAFETY_DISK_GB`，调度还须同时满足预算、就绪和新鲜度检查。内存配置的 MB 按 MiB 使用，磁盘 GB 按 GiB 使用。
- 写模式使用 root 或具备 libvirt 写权限、运行组文件权限和 ARP 工具权限的专用账号；升级沿用原账号，避免凭据/目录所有权变化。
- 控制台未启用时必须同时留空监听地址、公开地址和签名密钥。
- 私有状态目录须由 Agent 运行用户所有，且不能是 symlink；程序设为 `0700`，文件为 `0600`，同目录只允许一个进程。
- 显式同时填写 `AGENT_HOST_ID` 和 `AGENT_RUNTIME_TOKEN` 可导入轮换后的凭据；导入后可清空两项，普通重启使用 `credentials.json`。
- 不要删除/改动 `task.json` 或复制状态目录到另一台宿主；任务日志和凭据需要随升级备份保留，但不能作为公开诊断附件。
- 浏览器访问 HTTPS 平台时，入口仍为同源 WSS，内部控制节点到 Agent 可以使用受防火墙保护的 WS；`CONSOLE_ALLOWED_ORIGINS` 填真实页面 HTTPS Origin，19090 只对控制节点开放。
- 镜像下载不接受 HTTP/URL 用户名密码/重定向；私有 OSS 的 TLS 证书必须正常被系统信任，不能关校验。
- 固定预算与实测余量分别上报。详细镜像版本/缓存和交付规则见 [镜像与交付安全](镜像与交付安全.md)。
